# Everyday Simple Living

A static blog website built for Google AdSense approval readiness.

**Live site:** https://ahmad0098-commits.github.io/my-new-repo/

## Niche
Everyday Simple Living — practical tips on home organization, budgeting, routines, and daily habits.

## Site Structure
- `index.html` — blog homepage with article listing
- `posts/` — 5 full-length original articles
- `about.html`, `contact.html` — required info pages
- `privacy-policy.html` — includes Google AdSense cookie/ads disclosure
- `disclaimer.html`, `terms.html` — legal pages
- `sitemap.xml` — for search engine indexing
- `style.css` — single shared stylesheet (mobile responsive)

## AdSense Readiness Checklist
- [x] Original, value-adding content (5 articles, 600+ words each)
- [x] About page with editorial approach
- [x] Contact page (email + form)
- [x] Privacy Policy with third-party advertising / DART cookie disclosure
- [x] Disclaimer + Terms of Use
- [x] Clear navigation (header + footer) on every page
- [x] Mobile responsive layout
- [x] Sitemap for indexing
- [ ] AdSense ad units (add after approval via AdSense dashboard)
